## Summary
PR #104 replaces the cmd.exe-only `set NODE_OPTIONS=... && next dev ...` dev script in `frontend/package.json` with `cross-env NODE_OPTIONS=--max-old-space-size=4096 next dev --hostname 0.0.0.0`, preserving both the 4 GB heap option and the public hostname flag. `cross-env@^7.0.3` is added as a frontend-only devDependency, and the lockfile gains exactly one new `node_modules/cross-env` entry (with its workspace reference) at the correct alphabetical position with no transitive churn, since `cross-spawn` was already present. This fixes the root cause — on POSIX shells the old script silently ran `next dev` without the heap bump — and introduces no regressions.
